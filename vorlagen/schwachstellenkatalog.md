## Kategorien (als Suchraster durch den Ist-Prozess gehen)

| Kategorie | Leitfrage |
|---|---|
| **Medienbruch** | Wo wechselt das Medium (Papier → Datei → Ordner)? |
| **Doppelerfassung** | Wo wird dieselbe Information mehrfach erfasst? |
| **Suchaufwand** | Wo wird nach Informationen gesucht? |
| **Fehleranfälligkeit** | Wo entstehen Übertragungs-, Lese- oder Rechenfehler? |
| **Verzögerung** | Wo entstehen Wartezeiten oder Liegezeiten? |
| **Fehlende Transparenz** | Wer erfährt etwas zu spät oder gar nicht? |
| **Nachweislücke** | Was ist gegenüber der Fremdüberwachung schwer belegbar? |
| **Personenabhängigkeit** | Welches Wissen hat nur eine Person? |
| **Fehlende Durchgängigkeit** | Wo bricht die Rückverfolgbarkeit ab? |
| **Regelverstoß-Risiko** | Wo kann eine normative Pflicht unbemerkt verletzt werden? |

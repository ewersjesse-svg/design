**Kategorien für „Bezug zum System":**
- **Nutzer** — arbeitet direkt mit dem System
- **Entscheider** — entscheidet über Einführung, Budget, Ziele
- **Betroffener** — ist von den Ergebnissen betroffen, nutzt es aber nicht
- **Externer** — gibt Anforderungen vor (Norm, Überwachungsstelle, Gesetzgeber)

## 2. Einfluss-Betroffenheits-Matrix

```
             hohe Betroffenheit
                     │
   eng einbinden     │   aktiv managen
   (regelmäßig       │   (Hauptgesprächs-
    befragen)        │    partner)
  ───────────────────┼───────────────────  hoher Einfluss
   beobachten        │   zufriedenstellen
   (informieren)     │   (Ziele abholen,
                     │    nicht überfrachten)
                     │
             niedrige Betroffenheit
```

Trage die Stakeholder-IDs in die Quadranten ein. Die Personen oben rechts sind deine Hauptinterviewpartner.
